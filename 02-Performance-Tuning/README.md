# 02 - Performance Tuning

This folder contains Azure SQL Database performance tuning scripts and examples.

## Topics Covered

- Missing Index Recommendations
- Index Usage Analysis
- Expensive Query Detection
- Query Store
- Wait Statistics
- Index Fragmentation
- Statistics Maintenance
- Execution Plan Analysis

## Goal

Learn how to identify performance bottlenecks and improve Azure SQL Database performance using Dynamic Management Views (DMVs) and Azure SQL best practices.
